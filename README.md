One-line apology from a smart speaker that misheard its owner — for the
[Sorry, I Heard That Wrong](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729)
bounty on [make.fun](https://make.fun).

> Sorry, I heard 'add oat milk to the list'. I added a goat. It arrives Friday. It is named Oat.

`main.ts` (Node 22) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The gate requires 1–140 characters; the line is 94.

## Run

```sh
node main.ts
cat /output/entry.txt
```
